# DU'A Fashion POS System

A Point of Sale (POS) system for DU'A Fashion - Modesty Redefined.

## Live Site
https://pos.duafashion.store/login

## Recent Changes

### Add Items Form
- Removed SKU field (not needed in Nigerian system)
- Removed HSN field (not needed in Nigerian system)  
- Removed Profit Margin field
- Select Image is optional (no asterisk)

### Receipt Design (80mm Thermal Printer)
- Redesigned to fit X-printer / 80mm thermal roll paper
- Added company logo at top
- Shows: Store Name, Phone Number, Address
- Title: **RECEIPT** (not Invoice)
- Shows items with quantity and price
- Shows total, amount paid, change
- Footer: 'No Refund After Payment. Thank you for your patronage!'

## Tech Stack
- CodeIgniter PHP
- MySQL
- Bootstrap 3
